# งานขยายเขต C02.2: ติดตามงานบนมือถือ

> **"ใครทำอะไรเสร็จ ก็แค่กด เสร็จแล้ว"**

แอปใหม่ทำตามผัง `Flowchart งานขยายเขตงบผู้ใช้ไฟ C02.2.pdf` (14 ขั้น 7 หน่วยงาน) โดยนำแนวคิดจากโปรเจค `24-คำร้อง` มาลดขั้นตอนลง และออกแบบให้ใช้บนมือถือเป็นหลัก

## ลองใช้ทันที (โหมดทดลอง ไม่ต้องตั้งค่าอะไร)

```bash
python -m http.server 5173 --directory app
```

เปิด http://localhost:5173 แล้วเลือกหน่วยงาน ใส่ PIN **1234** (ผู้ดูแลใช้ **0000**)
ในโหมดนี้ข้อมูลจะอยู่ในเบราว์เซอร์ของเครื่องที่เปิดเท่านั้น ถ้าต้องการล้างข้อมูล ให้ไปที่เมนู (มุมขวาบน) แล้วกด "รีเซ็ตข้อมูลทดลอง"

## เทียบกับระบบเดิม

| เรื่อง | ระบบเดิม (24-คำร้อง) | ระบบใหม่ |
|---|---|---|
| อัปเดต 1 ขั้น | เข้าสู่ระบบ → หางาน → อัปเดต → ยืนยัน → พิมพ์หมายเหตุ → แนบไฟล์ (บังคับ) → ยืนยัน (**7 แตะ**) | เปิดแอป → **✓ เสร็จแล้ว** (**1 แตะ**) |
| เข้าสู่ระบบ | username + password ทุกครั้ง | เลือกหน่วยงาน + PIN 4 หลัก แล้วระบบจำไว้ |
| หน้าแรก | ตารางงานทั้งหมด ต้องกรองหาเอง | **คิวของฉัน** แสดงเฉพาะงานที่ถึงคิวหน่วยงานตัวเอง |
| ไฟล์แนบ | บังคับทุกขั้น | ไม่บังคับ ถ้าจะแนบให้กด 📷 ถ่ายรูป ระบบจะกดเสร็จให้เลย |
| กดผิด | ต้องให้ Admin แก้ | กด **เลิกทำ** ได้ภายใน 6 วินาที |
| ตรวจมาตรฐานไม่ผ่าน | ไม่มี | ปุ่ม ผ่าน/ไม่ผ่าน ถ้าไม่ผ่านให้แตะเลือกเหตุผล งานจะกลับไปที่ ผกส. และนับรอบแก้ไขให้ |
| งานค้างนาน | ไม่มี | แต่ละขั้นมี SLA ถ้าเกินกำหนดจะขึ้น ⏰ สีแดง |
| หน้าจอ | ตารางสำหรับเดสก์ท็อป | การ์ดขนาดนิ้วกด มีแถบเมนูล่าง bottom sheet ปัดลงเพื่อปิด และติดตั้งเป็นแอป (PWA) ได้ |

## อัปเดตด่วน: ทำเสร็จแล้ว แค่ส่งรูปหรือข้อมูล งานไหลต่อเอง

แยกตามสถานการณ์ของคนใช้งาน เพราะคนหน้างานกับคนในสำนักงานมีข้อจำกัดต่างกัน

| สถานการณ์ | วิธีอัปเดต | จำนวนแตะ |
|---|---|---|
| เปิดแอปอยู่แล้ว | **ปัดการ์ดไปทางขวา** หรือกด "เสร็จแล้ว" | 1 |
| อยู่หน้างาน (ผกส. ผปบ. ผมต. กรรมการ) | ปุ่มเหลืองกลางแถบล่าง → **ถ่ายรูปหน้างาน** ระบบดู GPS แล้วเลือกงานที่อยู่ใกล้ที่สุด (ภายใน 1.5 กม.) ให้เอง → กด "เสร็จแล้ว ส่งต่อ ..." | 3 |
| อยู่ในสำนักงาน ถือแฟ้มกระดาษ (ผบส. ผบร. ผสน.) | สแกน **QR ที่ติดหน้าแฟ้ม** จะใช้กล้องมือถือปกติหรือในแอปก็ได้ ระบบเปิดหน้าอัปเดตของแฟ้มนั้นทันที → กดเสร็จ | 2 |
| ได้ข้อความแจ้งเตือนใน LINE/Telegram | ข้อความมีลิงก์ของงานนั้น กดแล้วเข้าหน้าอัปเดตทันที | 2 |

ลูกเล่นในหน้าอัปเดต (ทุกอย่างไม่บังคับ):
- **ประทับรูปให้อัตโนมัติ** เหมือนแอปกล้องบันทึกเวลา รูปจะมีชื่องาน เลขคำร้อง ขั้น หน่วยงาน วันเวลา (พ.ศ.) และพิกัด ใช้เป็นหลักฐานได้
- **เห็นปลายทางก่อนกด** แถบด้านบนบอกว่าทำขั้นนี้เสร็จแล้วงานจะไปถึงใคร และข้ามขั้นที่มีคนทำล่วงหน้าไว้แล้วให้เอง
- **พูดแทนพิมพ์** กดไมค์ในช่องหมายเหตุแล้วพูดภาษาไทย (Chrome บน Android)
- **บันทึกความคืบหน้า** สำหรับงานที่ใช้เวลาหลายวัน เช่น ก่อสร้าง ส่งรูปความคืบหน้าได้โดยยังไม่ปิดขั้น
- **แอนิเมชันส่งต่อ** หลังกดเสร็จจะเห็นงานวิ่งจากหน่วยงานคุณไปหน่วยงานถัดไป
- **ไม่มีสัญญาณก็กดได้** (โหมด Google Sheet) ระบบเก็บไว้ในเครื่องแล้วส่งให้เองเมื่อมีเน็ต มีแถบบอกจำนวนรายการที่รอส่ง

### QR ประจำแฟ้ม
- ผบส. รับคำร้องใหม่แล้ว จะมีปุ่ม "พิมพ์ QR แฟ้ม" ขึ้นที่แถบด้านล่าง
- เปิดรายละเอียดงาน → ปุ่ม **QR แฟ้ม** → พิมพ์ฉลาก หรือแชร์ลิงก์
- เมนูมุมขวาบน → **พิมพ์ฉลาก QR ทุกแฟ้มที่กำลังทำ** (A4 หน้าละ 2 คอลัมน์ ตัดแปะหน้าแฟ้ม)
- QR เป็นลิงก์ธรรมดา (`…/index.html#u=รหัสงาน`) ต้องเปิดแอปจากที่อยู่เดียวกับตอนพิมพ์ ถ้าย้ายไปขึ้น Vercel ให้พิมพ์ฉลากใหม่จากที่อยู่จริง

### ข้อจำกัดที่ควรรู้
- กล้องสแกน QR และ GPS ต้องเปิดผ่าน **https** (เช่น Vercel) หรือ localhost เท่านั้น
- iPhone ไม่มีตัวสแกนในเบราว์เซอร์ ระบบใช้ไลบรารี jsQR แทนให้อัตโนมัติ หรือใช้แอปกล้องของ iPhone สแกนก็เปิดลิงก์ได้เลย
- พูดแทนพิมพ์ใช้ได้บน Chrome (Android/คอมพิวเตอร์) ส่วน Safari บน iPhone ใช้ไมค์บนแป้นพิมพ์แทนได้
- ตำแหน่งงานใช้คอลัมน์พิกัด (lat,long) ถ้างานไหนไม่มีพิกัด การถ่ายรูปหน้างานจะให้เลือกงานเองจากคิว

## หน้าจอ

1. **คิวของฉัน**: งานที่รอหน่วยงานคุณ เรียงตามความเร่งด่วน มีส่วน "ทำล่วงหน้าได้" (เช่น ผบส. สร้างคำร้องขอใช้ไฟระหว่างรอตรวจมาตรฐาน)
2. **งานทั้งหมด**: ค้นหาและกรองได้ (กำลังทำ / เกินกำหนด / จ่ายไฟแล้ว)
3. **ภาพรวม**: ผังงาน 14 ขั้นพร้อมจำนวนงานที่ค้างในแต่ละขั้น แตะขั้นไหนจะเห็นรายการงานของขั้นนั้น
4. **แจ้งเตือน**: ตัวอย่างข้อความที่จะส่งเข้า LINE/Telegram **(ตอนนี้ยังเป็น mock)**
5. **รายละเอียดงาน**: timeline 14 ขั้น (ใครทำ เมื่อไร มีรูปอะไร) ประวัติ ปุ่มโทร นำทาง แชร์ และแก้ไข

## ใช้งานจริงกับ Google Sheet

1. สร้าง Google Sheet ใหม่ แล้วไปที่ Extensions → Apps Script และวางไฟล์ `backend/Code.gs`
2. ใส่ค่า `SHEET_ID` และ `DRIVE_FOLDER_ID` แล้วกด Run `setup()` 1 ครั้ง ระบบจะสร้างชีต JOBS / LOG / USERS / OUTBOX ให้ ถ้าต้องการให้ข้อความแจ้งเตือนมีลิงก์เปิดหน้าอัปเดต ให้ใส่ Script Property `WEB_APP_URL` เป็นที่อยู่หน้าเว็บ
3. **เปลี่ยน PIN** ในชีต USERS (ค่าเริ่มต้นคือ 1234 และ ADMIN ใช้ 0000)
4. Deploy เป็น Web app (Execute as: Me, Who has access: Anyone)
5. นำ URL ที่ลงท้ายด้วย `/exec` ไปใส่ใน `app/config.js` ที่ `window.GAS_URL`
6. นำโฟลเดอร์ `app/` ไปขึ้น Vercel / Netlify / GitHub Pages ได้เลย เพราะเป็นไฟล์ static ไม่ต้อง build

## โครงสร้างไฟล์

```
app/
  index.html, config.js, manifest.webmanifest, icon.svg
  css/app.css   ← หน้าตาหลัก (พื้นขาว + เหลือง)
  css/quick.css ← หน้าอัปเดตด่วน สแกน QR แอนิเมชัน ฉลากพิมพ์
  js/flow.js    ← นิยาม 14 ขั้น / หน่วยงาน / SLA  (แก้ flow ที่นี่ที่เดียว)
  js/store.js   ← ชั้นข้อมูล: โหมดทดลอง (localStorage) หรือ Google Apps Script
  js/app.js     ← หน้าจอทั้งหมด
  js/quick.js   ← อัปเดตด่วน: ถ่ายรูป+GPS, ประทับรูป, QR แฟ้ม, พูดแทนพิมพ์, ปัดเพื่อเสร็จ, ออฟไลน์
backend/Code.gs ← API บน Google Apps Script + ฟังก์ชันแจ้งเตือน (mock)
```
